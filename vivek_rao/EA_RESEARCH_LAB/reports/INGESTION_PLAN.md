# EA Research Ingestion Plan

## Phase 1 — Extract, do not optimize
For each A+ repository, capture source repo, commit SHA, license, formulas, inputs, state variables, failure modes, and causal-data requirements.

## Phase 2 — AMOS EDGE mapping
Map each extracted component to Direction / Timing / Exit / Cost / Regime / Tail / Sizing.

## Phase 3 — EA translation
Only validated components are translated into modular EA research units under entry/regime/sizing/exit/risk/recovery/cost_model.

## Phase 4 — Nautilus gate
Execution-sensitive components must pass Raw Tick / Bid-Ask testing with reproducible configs and cost assumptions.

## Phase 5 — Promotion
No component is promoted solely on in-sample PF/return. Require robustness/OOS evidence and preserve the baseline for ablation.

## TickScalper rule
Vivek-derived components are external SAFE/BOOST candidates only. They must not be used to claim ORIGINAL TickScalper parity.
