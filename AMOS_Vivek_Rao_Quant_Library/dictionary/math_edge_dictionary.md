# Math EDGE Dictionary — Vivek Rao Import

## Admission rule
An item becomes an EDGE only after mechanism-level validation. Repository-level profitability is not sufficient.

Each EDGE card records:
- ORIGINAL mechanism
- AMOS mapping
- Mathematical object / estimator
- Inputs and state variables
- Action or diagnostic output
- Assumptions
- Leakage / overfit risks
- Failure modes
- Cost sensitivity
- OOS test
- Raw Tick relevance
- License / provenance
- Promotion status

## Initial candidate families
### Distribution / Tail
Heavy-tail fitting, skew-aware distributions, mixture distributions, conditional distribution diagnostics.

### Volatility / Regime
OHLC estimators, intraday volatility, GARCH-family conditional volatility.

### Backtest / Validation
Multiple-testing correction, out-of-sample Sharpe diagnostics, parameter redundancy and robustness.

### Data
Intraday ingestion, normalization, vendor/data-quality comparison.

### HFT / Execution
Only components that survive explicit tick-replay, spread, latency and transaction-cost gates may enter AMOS runtime.
